## 实际路径（按界面字面走）

1. 登录页只有「用户名」「密码」「进入工作台」；用户名已填 `admin`。登录后落在「工作台」。
2. 工作台首屏是运行次数、运行成本、专家数、连接器数、趋势图、最近运行；右上角「新建对话」是唯一明显行动按钮。
3. 点「新建对话」进入「对话」：空态「今天想完成什么？」，输入框「描述你想完成的事…」，**页面上没有任何选择专家的入口**。
4. 点左上角图标（无障碍名「显示会话历史」）后，左侧出现历史抽屉；抽屉顶部有一个显示 `md-tools-f307a5e9-4` 的控件，旁边是「+」；下方搜索框写「搜索对话」。**这个控件没有任何可见文字说明它是“选择专家”**。
5. 点该控件打开专家选择器，默认列表全是 `md-tools-xxxxxxxx-4` + 「通用助手」，无法区分。
6. 想创建自己的专家：从侧栏「专家·技能·连接器·插件·知识库」进入专家页，点「新建专家」。表单第一个必填项是英文「Slug」，另有「名称」「角色」「模型 claude-sonnet-5-5」「系统提示词」。
7. 创建成功，Toast 写「智能体已创建」；专家详情页没有任何「开始对话/使用」按钮。「更多操作」只有「克隆专家」「导出 ZIP」「删除专家」。
8. 只能回到侧栏「对话」，再打开历史抽屉、再打开专家选择器。先按界面上显示的 Slug 搜索 `qa-literal-20261028-01`，结果「没有匹配的专家」；按中文名称搜索「QA字面」才找到。
9. 选中后发送任务，约 8 秒收到回复，回复写「查看位置：/mnt/outputs/2026-10-28-项目周报.md，可在当前任务的输出文件区预览或下载。」
10. 界面上没有叫「输出文件区」的东西；右上角只有一个图标（无障碍名「显示工作区」）。点开后右侧面板标题是「会话成果」，文件可见，点文件名可预览，底部有「基于此版本修改」。

## 最高优先级文案 / 信息架构问题（可直接引用的原句）

1. **专家选择没有入口，也没有名字。** 对话页唯一入口是图标「显示会话历史」，抽屉顶部控件只显示 `md-tools-f307a5e9-4`。应把“当前专家”放到对话页可见位置（例如顶栏或输入框上方），并让入口文字直接写“选择专家/当前专家”。
2. **成果入口有三套叫法。** 回复说「输出文件区」，按钮是「显示工作区」（且只有图标），面板叫「会话成果」。应统一为一个用户词，并让回复里的指引用同一个词、指向看得见的按钮。
3. **创建专家是开发者表单。** 第一字段「Slug」* 高于「名称」；创建完没有“开始对话”。应把「名称」放第一且必填，Slug 折叠到高级设置；创建成功后直接给“开始对话”主按钮。
4. **选择器显示值与搜索值不一致。** 显示 `qa-literal-20261028-01`，照抄搜索得到「没有匹配的专家」。应按显示名称搜索，或显示名称而非 Slug。
5. **导航把五类资源串成一项。** 「专家·技能·连接器·插件·知识库」既难扫读，也掩盖了“专家=可对话助手”的主路径。
