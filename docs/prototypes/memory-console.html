运行期写入

决定模型在一次运行里能不能改自己的记忆。

模型自动写入
SDK auto-memory 开启，模型自行整理主题。写入不进账本，不可回滚。
仅提案
关闭 auto-memory，只能通过记忆提案写入。全部进账本，可回滚。
运行期只读
运行中不可写；平台手工编辑与提案仍可用。
当前选择会保留“边干边记”的效率，但记忆改动无法追溯。建议对长期运行的专家改为“仅提案”。
