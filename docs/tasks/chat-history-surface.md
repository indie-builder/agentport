# 对话历史与消息区同底、可折叠

## 目标
用户反馈三栏像三个独立侧栏。主导航维持画布底；会话列表与消息内容属于同一纸白工作区。列表可隐藏、展开，右侧不新增完整横向bar或专家选择器。

## 方案
- 会话列表和消息区共用 bg-surface，靠现有1px分隔区分。
- 原生 react-resizable-panels v4 Panel collapsible/0px/panelRef + useDefaultLayout 负责布局及宽度恢复，不新建存储。
- 展开态收起动作在历史标题旁；收起态右内容左上角浮动展开按钮，不占整行。隐藏内容不可tab，焦点交接。
- 移动端沿用Sheet，专家选择只在历史抽屉，保证一处h1和新建入口。
- 不改变流式、审批、分支和输入草稿逻辑。

## 追加：折叠入口与专家选择（2026-10-25）
用户反馈两个折叠按钮并列难辨，且专家头像应与所选专家同步。处理：
- 展开态只在列头保留一个「收起会话列表」；收起态只在内容区左上角保留一个「展开会话列表」，两者互斥，均与主导航品牌区的折叠分离。
- 专家选择改为 Combobox：输入即过滤名称，下拉项与输入框左侧都显示对应专家头像，空结果显示「没有匹配的专家」。
- 可访问角色仍为 `role="combobox"`、名称「选择专家」，E2E 定位不变。

实测：展开态收起按钮 1 个（x=428,y=16）、主导航折叠 1 个（x=228,y=24）；收起态展开按钮 1 个（x=280,y=12），仍只有 1 个 h1。搜索「E2E」只剩 1 个选项，搜索不存在名称显示空态；选中后 URL 与输入值同步。272 条测试、typecheck、build、契约检查通过。
