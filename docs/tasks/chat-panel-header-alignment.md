# 导航品牌与左右面板控件对齐

## 目标

## 方案
- 历史保留PanelLeft，产出从GalleryHorizontalEnd改为PanelRight；共用ghost/icon32和全局16px图标。

- 主导航顶部16内边距不变，按钮cy32应与外壳y4+消息头56/2=32一致，无负margin/额外pt补偿。
