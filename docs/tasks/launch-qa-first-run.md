## 评审中发现并修复

- 请求接受前立即清持久草稿会在切走/失败或刷新时丢稿：改为输入框先清，持久槽保留到接受；失败恢复原始正文，含首尾空白。
- 迟到请求清空共用新会话槽、等待期间新写同文被文本比较误清：先检查请求归属，再仅在最新输入框为空时清原槽；新草稿随新会话ID迁移。
- 桌面窗口缩放前后历史面板可见性不一致，可能三处专家选择器都隐藏：改为按当前断点下实际可见历史区域判断。
- 权限说明原先笼统写“无需批准”：修正为SDK层预批准，工具自身服务端审批仍然生效。
- 上述修复经独立Opus代码复核。核心定点最终复核见接受回调、clearDraft及新增页面交互测试；并非以实现者自报作为review通过。
