# 品牌 Logo：轻推接力

## 当前决定
用户选择动效对比中的第一种「轻推接力」。点击 Logo 切换下一张，旧图向左轻退淡出，新图同时从右侧淡入，全程 300ms。无转盘、弹跳、自动轮播或刷新随机换图；业务页面不额外插入插画。

## 实现范围
- 共享品牌组件固定正方形占位，两个 React 图层同步交接，次图装饰性隐藏。
- 使用现有 Motion mini DOM 接口，先解码下一张，再开始动画；完成后释放播放状态并隐藏次图。
- 96px 的位移为 8px，32px 导航按比例缩小；转场中忽略连点。减少动态效果时直接换图。
- 登录页及展开侧栏的 Logo 按钮只切图，不触发登录或路由跳转。初始沿用原 Logo，随后循环六张变体。
- 素材为 public/brand/scenarios 的六张 WebP，无新增依赖、后端和数据改动。

## 验证

- 登录页宽 96px、导航宽 32px，切换后大小不变；导航点击仍停留 /chat。六张素材循环成功。
