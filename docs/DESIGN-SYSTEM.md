# PACE 设计规范（以 OpenUI Chat 为基准）

> 2026-10-21。**唯一设计基准：https://www.openui.com/chat?form_factor=desktop**
> 数值全部通过 ego-browser（CDP）读取计算样式获得，不是目测。

---

## 1. 整体结构

```
body #F7F7F5
└─ 外壳：margin 4px，圆角 16px，白底 #FEFEFD，占满剩余视口
   ├─ 侧栏（展开 310px / 折叠 64px，白底，1px 分隔线）
   └─ 主区
      ├─ 顶部一行：模型/智能体选择器（左）· 工具图标（右）
      ├─ 内容：最大宽 728px，水平居中
      └─ 底部：胶囊输入框（728×56，圆角 28px）
```

**硬性规则**

1. 外层留 4px 边距；内容装在一张 16px 圆角的白壳里，壳本身没有边框与阴影。
2. 侧栏与外层同色，只靠 1px `rgba(0,0,0,.06)` 分隔。
3. 顶部只有一行，高度约 56px；没有「页面标题 + 描述 + 卡片网格」。
4. 对话、空态、输入框共用同一条 728px 轴线。

## 2. 色彩

参考页是**无彩度**设计：黑、白、灰承担全部层级，没有品牌色。

| 用途 | 值 | 来源 |
|---|---|---|
| 页面背景 | `oklch(0.97 0 89.876)` ≈ `#F7F7F5` | body |
| 外壳 / 卡片 | `oklch(0.994 0 89.876)` ≈ `#FEFEFD` | shell |
| 主文本 | `oklch(0.097 0 0)` ≈ `#0F0F0F` | heading |
| 次要文本 | `oklch(0.097 0 0 / 0.6)` | 第二行标题、占位符 |
| 弱文本 | `rgba(0,0,0,.38)` | 分组标题、时间 |
| 分隔线 | `rgba(0,0,0,.06)` | shell border |
| 浅底（悬停 / 建议卡） | `oklch(0.097 0 0 / 0.02)`–`0.04` | chip / nav |
| 主按钮 / 发送 | `oklch(0.097 0 0)` 实底 | send button |
| 状态 | 成功 `#1A7F4B` / 警告 `#8A5600` / 失败 `#B42318` | 仅小面积 |

> 取消上一版的「信号橙」。强调靠黑与灰的对比，不靠色相。

## 3. 圆角（实测值）

| 元素 | 半径 |
|---|---|
| 外壳 | **16px** |
| 输入框胶囊 | **28px** |
| 建议卡 | **16px** |
| 对话气泡 / 内容卡 | 12px |
| 侧栏项 / 小按钮 | **9px** |
| 图标按钮 | 7px |
| 小标签 | 6px |
| 头像 / 圆形按钮 | 9999px |

## 4. 字体

- 字体：**Inter**（`Inter, "Inter Fallback", system-ui, sans-serif`）。等宽：**Geist Mono**，回退 JetBrains Mono。
- 主体 15px（textarea）/ 14px（nav、chip）。
- **空态两行标题都是 24px**：
  - 第一行 `600`（实测 400，但视觉上标题需更重，取 500）实际按实测：**500 / 24px / 30px 行高**，主文本色。
  - 第二行 **500 / 24px**，`rgba(0,0,0,.6)`。
- 说明文字 13px，弱色。

> 标题不靠加粗堆叠，靠**颜色透明度**分层：第一行实色，第二行 60%。

## 5. 图标

- **lucide**，`stroke-width: 1.75`，尺寸 **16px**（次级 14px，最小 12px）。
- 图标跟随文本色，不单独着色。
- 品牌：lucide 线框标记 + `PACE` 文字（12.5px，字距 0.14em）。

## 6. 对话页（核心）

### 空态

```
[ 智能体选择器 ▾ ]                         ← 顶部一行
（垂直居中于内容区）
        Good to see you                     ← 24px / 500 / 实色
    What's on your mind today?              ← 24px / 500 / 60%

┌────────────────────────────────────────┐
│  Ask anything...                  (↑)  │  ← 728×56，radius 28
└────────────────────────────────────────┘
  [ 建议卡 ] [ 建议卡 ] [ 建议卡 ] [ 建议卡 ]  ← 136×72，radius 16
```

- 输入框外壳：白底、`1px solid transparent`、双层阴影
  `0 0 0 .5px rgba(0,0,0,.08), 0 4px 16px rgba(0,0,0,.06)`，
  内边距 `11px 12px 11px 24px`。
- 发送按钮：**32×32 圆形黑底**，白色箭头，位于输入框右侧内缘。
- 建议卡：136×72，`rgba(0,0,0,.02)`，16px 圆角，16px 内边距，14px 文字 / 60% 灰，两行截断。
- 不显示「绑定 server / 权限 / 最近运行」等元信息。

### 对话态

- 消息流最大宽 728px，居中。
- 用户消息：右对齐，**黑底白字胶囊**（radius 9999 / 20px）。
- 助手消息：左对齐，无气泡，15–16px 正文；可含标题、列表、卡片。
- 工具调用：单行「图标 + 名称 + 状态 + 耗时」，点击展开参数/结果；不用厚边框。
- 底部输入框常驻，形态同空态。

## 7. 侧栏

- 展开 310px：顶部折叠按钮（32×32，radius 7）；「新建对话」行高 36px，radius 9，选中浅灰底；分组标题 12px 弱色；条目 14px + 16px 图标。
- 折叠 64px：仅图标居中。
- 底部：1px 分隔线之上放状态入口。
- 选中态 = 浅灰底 + 深色文字，**没有彩色竖条**。

## 8. 其他页面

1. 同一个外壳：4px 外边距、16px 圆角、白底。
2. 顶部一行：名称 + 主操作，不超过 56px。
3. 列表用行不用卡片网格：行高 56–64px，1px 分隔线，悬停 `rgba(0,0,0,.02)`。
4. 详情用右栏或抽屉。
5. 表格：表头 12px 弱色，行 14px，数字右对齐 + 等宽。
6. 主按钮：黑底白字，radius 9999（胶囊）或 9px（紧凑）。

## 9. 动效

- 150–200ms，ease-out。
- 只有：悬停背景、展开折叠、流式光标。
- 无入场动画、无位移、无呼吸点。

## 10. 实现技术栈（硬性）

视觉由上文的数值决定，交互与结构由下列库决定。**不得手写这些库已经提供的东西**：

| 需求 | 唯一实现 | 约束 |
|---|---|---|
| 控件、表单、浮层 | shadcn/ui（`components/ui/`）+ Radix | 新增先 `pnpm dlx shadcn@latest add <name>`，再把外观换成 `@theme` 令牌 |
| 图标 | lucide | `LucideProvider` 在 `App.tsx` 统一设 `strokeWidth={1.75}`、`size={16}`，组件里不要再逐个传 |
| 动效 | Motion（`motion/react`） | 只用于 §9 允许的三类；`duration` 0.15–0.2、`easeOut`；读 `useReducedMotion` |
| 可拖拽分栏 | react-resizable-panels v4 | `Group` / `Panel` / `Separator`；用 `useDefaultLayout` 持久化；分隔条就是 1px `border-line`，不加把手 |
| 拖拽排序 | dnd-kit | 必须带 `KeyboardSensor`，拖拽手柄有可访问名称 |
| 客户端状态 | Zustand | 只放**跨组件、非服务端**的状态；服务端数据一律 TanStack Query |
| 路由与 URL 状态 | TanStack Router | 筛选、分页、选中的 tab 走 `validateSearch`，不要塞进组件 state |
| 类名合并 | `cn`（`lib/cn.ts`） | 唯一实现，不引入 clsx / tailwind-merge 的第二份 |

- 圆角一律从令牌取值：外壳 16 / 卡片 12 / 行 9 / 图标 7 / 标签 6。控件用 7，容器用 12，不要出现 2px、3px 这类体系外的值。
- 动画类（`animate-in` / `fade-in-0` / `zoom-in-95`）由 `tw-animate-css` 提供，已在 `styles.css` 引入。
- shadcn 原语的语义色（`bg-popover`、`text-muted-foreground`、`bg-accent` 等）已全部映射到无彩度令牌，**不要在组件里改回具体色值**。

## 11. 禁止

- 卡片套卡片、彩色边框、彩色左边条。
- 渐变、玻璃、阴影堆叠（外壳无阴影，输入框是唯一带阴影的元素）。
- emoji 当图标。
- 一页多个同等权重标题。
- 彩色品牌色（参考页没有）。
