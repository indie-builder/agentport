# Agentport / PACE — 用户故事与功能契约

> 本文件是功能验收的唯一依据。每条用户故事都有明确的验收条件。
> 品牌：对外产品名为 **PACE**；仓库与包名保持 `agentport`。

---

## 角色

| 角色 | 说明 |
|---|---|
| **管理员** | 唯一登录用户，配置 MCP Server、智能体、技能 |
| **操作员** | 使用智能体对话、查看历史（当前与管理员同一账号） |
| **外部 Host** | 通过 `/mcp/:serverId` 连接平台的 MCP 端点（Claude Code、其他客户端） |

---

## EPIC 1 — MCP Server 管理

### US-1.1 登记一个 stdio MCP Server
**作为** 管理员，**我想** 填写命令、参数、环境变量并保存，**以便** 平台能启动它。

验收：
- 表单校验 `name` 为 `[a-z0-9-_]`、`command` 非空。
- 敏感 env 加密入库，列表与详情返回 `••••`。
- 保存后立即可在「测试连接」中使用。

### US-1.2 登记一个远程 MCP Server
**作为** 管理员，**我想** 填写 URL 与请求头，**以便** 复用已有的远程 MCP 服务。

验收：
- 仅允许 http/https；SSRF 校验（生产拒绝私网，开发放行 localhost）。
- headers 中的密钥脱敏返回。

### US-1.3 把一个 HTTP API 变成 MCP Server
**作为** 管理员，**我想** 填写 baseUrl 并定义若干工具（method、path、参数 schema），**以便** 不写代码就把内部 API 暴露给智能体。

验收：
- 支持 `GET/POST/PUT/PATCH/DELETE`，路径模板 `{param}` 自动替换。
- `paramsIn` 决定参数进 query 还是 body。
- 保存后平台生成 `/mcp/:serverId` 端点，带 Bearer token。
- 「测试连接」走平台端点，能看到工具列表。

### US-1.4 测试连接
**作为** 管理员，**我想** 一键验证配置，**以便** 在绑定给智能体前发现错误。

验收：
- 5 秒超时；失败返回可读错误，不抛 500。
- 成功展示 serverInfo、工具名与描述、耗时。
- 每次测试写入审计。

## EPIC 2 — 智能体定义

### US-2.1 创建智能体
**作为** 管理员，**我想** 定义名称、模型、系统提示词，**以便** 建立人格与行为边界。

验收：
- slug 唯一，创建后不可改（目录名）。
- model 可为任意模型 ID；提供常用建议值。
- 系统提示词写入 `CLAUDE.md`。

### US-2.2 绑定 MCP Server
**作为** 管理员，**我想** 选择若干 MCP Server，**以便** 智能体能使用它们的工具。

验收：
- 绑定关系存入数据库。
- 工作区 `.mcp.json` 包含全部绑定 server。
- 智能体的 `tools` 自动生成 `mcp__<server>__*`。

### US-2.3 绑定技能（Skills）
**作为** 管理员，**我想** 给智能体挂载「技能包」，**以便** 复用可复用的操作流程，而不用把它们塞进系统提示词。

验收：
- 技能是带 frontmatter 的 Markdown（`SKILL.md`），含 `name`、`description`。
- 可全局创建、可被多个智能体复用。
- 渲染到工作区 `.claude/skills/<slug>/SKILL.md`。
- 智能体 frontmatter 的 `skills` 字段列出已挂载技能。

### US-2.4 配置权限与运行时
**作为** 管理员，**我想** 控制智能体能做什么、花多少、跑多久。

验收：
- 可配置 `permissionMode`、`allowedTools`、`disallowedTools`。
- `permissionMode` 支持 `dontAsk`（默认）、`plan`、`default` 与 `acceptEdits`，直接透传 Agent SDK；`auto` 依赖模型分类器，平台无法审计其决定，保存时返回 400。权限模式不会解除平台固定禁用的内置工具。
- 可配置 `maxTurns`、`maxBudgetUsd`、`timeoutMs`。
- 可配置 `effort` 与 `maxThinkingTokens`（可选）。
- 默认关闭所有内置工具（Bash/Read/Write/Edit/WebFetch…）。

### US-2.5 预览生成的文件
**作为** 管理员，**我想** 在保存前看到将要落盘的 `.mcp.json`、`CLAUDE.md`、agent md、skills，**以便** 确认配置正确。

验收：
- 文件预览与运行时实际生成内容一致。
- 支持复制。

### US-2.6 删除智能体
**作为** 管理员，**我想** 删除不再需要的智能体。

验收：二次确认；级联删除绑定关系与会话。

## EPIC 3 — 对话

### US-3.1 发起对话
**作为** 操作员，**我想** 选一个智能体并发送消息，**以便** 让它替我完成任务。

验收：
- 返回 202 与 `runId`、`conversationId`。
- 智能体不存在返回 404；停用返回 409 `AGENT_DISABLED`。
- 触发限流时返回 429。

### US-3.2 流式输出
**作为** 操作员，**我想** 实时看到文本与工具调用，**以便** 知道它在做什么。

验收：
- SSE 依次推送 `run_started`、`text_delta`、`tool_start`、`tool_input`、`tool_result`、`run_finished`。
- 订阅前的历史事件可回放（Redis Stream），不丢失。
- 客户端断开不泄漏 Redis 连接。

### US-3.3 对话历史
**作为** 操作员，**我想** 看到历史消息并在同一会话中继续对话，**以便** 保持上下文。

验收：
- 会话列表按 agent 过滤，按最近更新排序。
- 打开会话加载全部消息（含工具调用）。
- 继续提问时模型能看到之前的上下文（SDK session 复用或历史注入）。
- 刷新页面后历史仍在。

### US-3.4 取消运行
**作为** 操作员，**我想** 中途停止，**以便** 避免继续消耗。

验收：已终态幂等；运行中在数秒内终止沙盒容器。

### US-3.5 运行状态与成本
**作为** 管理员，**我想** 看到每次运行的状态、耗时、轮次、成本。

验收：`agent_runs` 全字段落库；概览页展示最近 20 条与最近 7 天聚合。

---

### US-3.6 会话操作菜单
**作为** 操作员，**我想** 在当前会话的短标题旁打开更多菜单，管理会话而不先展开历史列表。

验收：
- 标题短显，完整名称可读取；菜单紧随标题。
- 重命名更新当前标题与列表，Fork 复制已有消息到独立会话。
- 删除必须明确确认；删除当前会话、消息和已结束运行记录，已有 Fork 保留。
- queued/running 会话返回 409，删除失败保留原会话和未发送输入。
- 尚未保存的新会话不提供可执行的操作；删除中禁止重复提交、继续发送或离开。

## EPIC 4 — 平台与运维

### US-4.1 登录
**作为** 管理员，**我想** 用账号密码登录，**以便** 保护配置。

验收：httpOnly cookie；scrypt 校验；错误不区分用户名/密码；登录限流。

### US-4.2 概览
**作为** 管理员，**我想** 一眼看到规模与最近运行。

验收：servers/agents/runs/running 计数 + 最近 20 条运行。

### US-4.3 审计
**作为** 管理员，**我想** 追溯关键操作。

验收：配置变更、连接测试、对话请求/取消、运行起止都有记录；只存摘要。

### US-4.4 健康检查
验收：`/health/live` 与 `/health/ready`（DB + Redis）。

### US-4.5 部署
**作为** 运维，**我想** 用一条命令在本机或服务器跑起来。

验收：`pnpm run up` 一条命令完成依赖启动、沙盒镜像构建、迁移、api/worker 启动与冒烟，结束后 api/worker/web 可用；迁移由 compose 的 `migrate` 服务在 api 启动前自动执行（直接操作宿主机时仍可手动 `pnpm db:migrate`）。

## 非功能需求

| 维度 | 要求 |
|---|---|
| 安全 | 密钥加密、SSRF 防护、容器隔离、日志脱敏、限流 |
| 可观测 | 结构化日志 + runId 关联 + 审计表 |
| 可靠性 | 队列重试策略明确；取消与超时在所有路径生效 |
| 性能 | 首字节 < 1s（不含模型延迟）；列表接口 P95 < 200ms |
| 可访问性 | 键盘可达；对比度 ≥ WCAG AA；焦点可见 |
| 可测试 | 每条用户故事至少一个自动化测试或明确的手工验收步骤 |
